# Bangladesh Govt Job (IT/CSE) Operating Systems Exam Guide & MCQs

> Target Exams: BPSC (Assistant Network/Database Engineer, Assistant Programmer), Bank IT (Senior Officer IT / Officer IT), Ministry IT posts, BUET/DU/DUET pattern exams.

---

## 1. Top Frequently Asked Theory Topics in Bangladesh Govt Job IT Exams

1. **OS Generations & Evolution (Very High Frequency in MCQs)**
   - Generations by decade & technology:
     - **1st Gen (1945–1955):** Vacuum Tubes, Plugboards (No OS)
     - **2nd Gen (1955–1965):** Transistors, Batch Processing (FMS, IBSYS)
     - **3rd Gen (1965–1980):** Integrated Circuits (ICs), Multiprogramming & Time-sharing (OS/360, UNIX 1969)
     - **4th Gen (1980–Present):** Microprocessors (VLSI/ULSI), GUI, Personal Computers (DOS 1981, Windows 1985, Linux 1991)
   - Creator/Inventor Matchings:
     - **UNIX:** Ken Thompson & Dennis Ritchie (AT&T Bell Labs, 1969, written in C)
     - **Linux Kernel:** Linus Torvalds (1991, Helsinki)
     - **MS-DOS:** Microsoft / Tim Paterson (1981)

2. **Process Management & CPU Scheduling**
   - **Process States:** New $\rightarrow$ Ready $\rightarrow$ Running $\rightarrow$ Waiting/Blocked $\rightarrow$ Terminated.
   - **PCB Contents:** PID, Program Counter, CPU Registers, Memory Limits, Open File List.
   - **Scheduling Criteria Formulas:**
     $$\text{Turnaround Time (TAT)} = \text{Completion Time (CT)} - \text{Arrival Time (AT)}$$
     $$\text{Waiting Time (WT)} = \text{Turnaround Time (TAT)} - \text{Burst Time (BT)}$$
     $$\text{Response Time (RT)} = \text{First Executed Time} - \text{Arrival Time (AT)}$$
   - **Algorithm Characteristics:**
     - **FCFS:** Non-preemptive, suffers from *Convoy Effect*.
     - **SJF:** Gives minimum average waiting time (Optimal), can cause *Starvation*.
     - **SRTF:** Preemptive SJF.
     - **Round Robin:** Time Quantum based, preemptive, optimal for Time-sharing systems.
     - **Priority Scheduling:** Can cause starvation (Solved by *Aging*).

3. **Process Synchronization & Deadlock**
   - **Critical Section Requirements:** 1. Mutual Exclusion, 2. Progress, 3. Bounded Waiting.
   - **Semaphore vs Mutex:** Mutex is locking (ownership), Semaphore is signaling mechanism.
   - **4 Necessary Conditions for Deadlock:**
     1. Mutual Exclusion
     2. Hold and Wait
     3. No Preemption
     4. Circular Wait
   - **Deadlock Avoidance:** Banker's Algorithm (checks Safe State using $\text{Need} = \text{Max} - \text{Allocation}$).

4. **Memory Management & Paging**
   - **Fragmentation:** Internal (Paging fixes, but small remains inside last page), External (Compaction/Paging fixes).
   - **Page Fault Handling Steps:** Trap $\rightarrow$ Save State $\rightarrow$ Disk I/O $\rightarrow$ Update Page Table $\rightarrow$ Resume.
   - **Belady's Anomaly:** Increasing the number of frames increases page faults (occurs in FIFO, NOT in LRU/Optimal).
   - **Address Calculation Formulas:**
     $$\text{Page Offset Bits} = \log_2(\text{Page Size in Bytes})$$
     $$\text{Physical Address} = (\text{Frame Number} \times \text{Page Size}) + \text{Offset}$$

5. **Linux Administration & Commands (BUET / Bank IT Pattern)**
   - Permissions: `r=4, w=2, x=1`. Example: `chmod 755 script.sh` (Owner: rwx, Group: r-x, Others: r-x).
   - `umask`: Default dir `777`, file `666`. If `umask = 022`, default file perm = `644` (`rw-r--r--`).
   - Essential Commands: `ps aux`, `top`, `kill -9`, `chmod`, `chown`, `grep -i`, `find`, `df -h`, `du -sh`.

## 2. Model Questions for Practice (BD Govt IT Exam Pattern)

### Multiple Choice Questions (MCQs)

**Q1.** Which generation of operating systems introduced multiprogramming and time-sharing?  
(A) First Generation  
(B) Second Generation  
(C) Third Generation  
(D) Fourth Generation  
**Answer:** (C) Third Generation (1965–1980, using ICs)

**Q2.** Which CPU scheduling algorithm suffers from Belady's Anomaly?  
(A) LRU  
(B) Optimal  
(C) FIFO  
(D) Round Robin  
**Answer:** (C) FIFO

**Q3.** What is the default permission of a newly created file if the `umask` is set to `022`?  
(A) 755  
(B) 644  
(C) 666  
(D) 777  
**Answer:** (B) 644 (Calculated as $666 - 022 = 644$)

**Q4.** Which condition is NOT necessary for a deadlock to occur?  
(A) Circular Wait  
(B) Preemption  
(C) Mutual Exclusion  
(D) Hold and Wait  
**Answer:** (B) Preemption (No preemption is required, not preemption)

**Q5.** In Linux, which command is used to display disk space usage in human-readable format?  
(A) `du -sh`  
(B) `df -h`  
(C) `free -m`  
(D) `top`  
**Answer:** (B) `df -h`

### Written / Numerical Problem Patterns

#### Problem 1: CPU Scheduling (Gantt Chart & Waiting Time Calculation)
Given 3 processes with arrival time 0:
- $P_1$: Burst Time = 24 ms
- $P_2$: Burst Time = 3 ms
- $P_3$: Burst Time = 3 ms

*Calculate Average Waiting Time using FCFS.*

**Solution:**
- Gantt Chart: `| P1 (0-24) | P2 (24-27) | P3 (27-30) |`
- Waiting Time:
  - $WT(P_1) = 0$
  - $WT(P_2) = 24$
  - $WT(P_3) = 27$
- Average Waiting Time = $\frac{0 + 24 + 27}{3} = \frac{51}{3} = 17\text{ ms}$.

#### Problem 2: Logical to Physical Address Translation
System with page size 4 KB ($4096\text{ bytes} = 2^{12}\text{ bytes}$). Logical address = 5000.  
Page Table Entry for Page 1 maps to Frame 5.  

*Calculate Page Number, Offset, and Physical Address.*

**Solution:**
- Page Number = $\lfloor 5000 / 4096 \rfloor = 1$
- Offset = $5000 \pmod{4096} = 904$
- Frame Number = 5
- Physical Address = $(5 \times 4096) + 904 = 20480 + 904 = 21384$.
