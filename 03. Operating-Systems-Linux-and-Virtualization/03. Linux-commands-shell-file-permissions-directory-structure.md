Comprehensive coverage of Linux operating system basics — features, file system hierarchy, essential commands, shell concepts, and file permissions.

## 18. Linux Basics ⭐

### Linux Features
1. **Open Source** — Free to use, modify, and distribute (GNU GPL license)
2. **Multi-user** — Multiple users can access the system simultaneously
3. **Multitasking** — Runs multiple processes concurrently
4. **Portable** — Runs on various hardware platforms (x86, ARM, RISC-V)
5. **Security** — Built-in firewall, file permissions, user isolation
6. **Stability** — Rarely crashes; can run for years without reboot
7. **Networking** — Robust networking stack; supports all major protocols
8. **Shell & Scripting** — Powerful command-line interface with automation (Bash scripts)
9. **Package Management** — Easy software install/update via apt, yum, dnf, pacman

### Linux File System (FHS — Filesystem Hierarchy Standard)

| Directory | Purpose |
|---|---|
| `/` (Root) | Top-level directory; all files and directories originate from here |
| `/bin` | Essential user binaries (commands like `ls`, `cp`, `mv`) |
| `/sbin` | System binaries (administrative commands like `fdisk`, `shutdown`) |
| `/etc` | System configuration files (passwd, fstab, ssh config) |
| `/home` | User home directories `/home/username` |
| `/root` | Home directory for the root user |
| `/var` | Variable data (logs, databases, mail spools) |
| `/tmp` | Temporary files (cleared on reboot) |
| `/usr` | User system resources (binaries, libraries, documentation) |
| `/opt` | Optional third-party software |
| `/dev` | Device files (hardware interface points) |
| `/proc` | Virtual filesystem with process and kernel information |
| `/mnt` | Temporary mount point for filesystems |
| `/media` | Mount point for removable media (CD-ROM, USB) |

### Absolute Path vs Relative Path

| Aspect | Absolute Path | Relative Path |
|---|---|---|
| Definition | Full path from root (`/`) | Path relative to current directory |
| Starts with | `/` | Current directory (`.`) or parent (`..`) |
| Example | `/home/user/Documents/file.txt` | `Documents/file.txt` or `../file.txt` |
| Always valid | Yes | No (depends on current working directory) |

### Essential Linux Commands ⭐

#### Navigation & Directory Commands

| Command | Description | Example |
|---|---|---|
| `pwd` | Print Working Directory — shows current directory path | `pwd` → `/home/user` |
| `ls` | List directory contents | `ls -la` (detailed, including hidden) |
| `cd` | Change Directory | `cd /var/log` or `cd ..` (parent) |
| `mkdir` | Create a new directory | `mkdir project` or `mkdir -p a/b/c` (nested) |
| `rmdir` | Remove an empty directory | `rmdir emptydir` |

#### File Manipulation Commands

| Command | Description | Example |
|---|---|---|
| `touch` | Create empty file or update timestamp | `touch file.txt` |
| `cp` | Copy files or directories | `cp src.txt dst.txt` or `cp -r dir1 dir2` |
| `mv` | Move or rename files/directories | `mv old.txt new.txt` |
| `rm` | Remove files or directories | `rm file.txt` or `rm -rf dir/` |
| `cat` | Display file content / concatenate | `cat file.txt` |
| `more` | View file content page by page (forward only) | `more longfile.txt` |
| `less` | View file content with backward/forward navigation | `less longfile.txt` |
| `head` | Show first N lines of a file (default: 10) | `head -20 file.txt` |
| `tail` | Show last N lines of a file (default: 10) | `tail -f log.txt` (follow mode) |

#### Permission Commands

| Command | Description | Example |
|---|---|---|
| `chmod` | Change file permissions | `chmod 755 script.sh` or `chmod u+x script.sh` |
| `chown` | Change file owner and group | `chown user:group file.txt` |

#### Search & Text Processing

| Command | Description | Example |
|---|---|---|
| `grep` | Search for patterns in files | `grep "error" log.txt` or `grep -r "TODO" .` |
| `find` | Search for files by name, type, size, etc. | `find /home -name "*.txt"` |

#### Process Management Commands

| Command | Description | Example |
|---|---|---|
| `ps` | Display current processes | `ps aux` (all processes, detailed) |
| `top` | Real-time process monitoring | `top` (press `q` to quit) |
| `kill` | Terminate a process by PID | `kill -9 1234` |

#### System Information Commands

| Command | Description | Example |
|---|---|---|
| `man` | Display manual page for any command | `man ls` |
| `who` | Show who is logged in | `who` or `whoami` |
| `uname` | Display system information (kernel, architecture) | `uname -a` |
| `df` | Display disk space usage of filesystems | `df -h` (human-readable) |
| `du` | Display disk usage of files/directories | `du -sh /home/user` |

### File Permissions (rwx, Octal Notation, umask)

#### Permission Types
```
r = read (4)    — View file contents / list directory
w = write (2)   — Modify file / create/delete files in directory
x = execute (1) — Run file / access directory (cd into it)
- = no permission (0)
```

#### Permission Groups
| Group | Symbol | Description |
|---|---|---|
| User/Owner | `u` | The owner of the file |
| Group | `g` | Members of the file's group |
| Others | `o` | Everyone else |

#### Permission Representation
```
Example:  rwxr-xr--
Breakdown:
  rwx  → Owner: read, write, execute  (7)
  r-x  → Group: read, execute         (5)
  r--  → Others: read only            (4)
```

#### Octal Notation
| Octal | Binary | rwx |
|---|---|---|
| 0 | 000 | `---` |
| 1 | 001 | `--x` |
| 2 | 010 | `-w-` |
| 3 | 011 | `-wx` |
| 4 | 100 | `r--` |
| 5 | 101 | `r-x` |
| 6 | 110 | `rw-` |
| 7 | 111 | `rwx` |

**Common permissions:**
- `chmod 755 file` → Owner: rwx, Group: r-x, Others: r-x (executables)
- `chmod 644 file` → Owner: rw-, Group: r--, Others: r-- (regular files)
- `chmod 600 file` → Owner: rw-, Group: ---, Others: --- (private files)

#### umask
**umask** (User file-creation Mask) sets default permissions for new files and directories. It subtracts from the maximum default permissions:
- Default file permissions: `666` (rw-rw-rw-)
- Default directory permissions: `777` (rwxrwxrwx)
- A umask of `022` results in:
  - File: `666 - 022 = 644` (rw-r--r--)
  - Directory: `777 - 022 = 755` (rwxr-xr-x)

### Shell Concepts

**Shell** — A command interpreter that provides a user interface to access OS services.
- **Bash** (Bourne Again Shell) — Most common Linux shell
- **Zsh** — Enhanced shell with advanced features (Oh My Zsh)
- **Fish** — User-friendly shell with auto-suggestions

**Pipes (`|`)** — Connect commands; output of first command becomes input to second:
```bash
ls -la | grep "txt"   # List files and filter for "txt"
ps aux | grep firefox # Find firefox process
```

**Redirection:**
| Operator | Description | Example |
|---|---|---|
| `>` | Redirect stdout to file (overwrite) | `echo "hello" > file.txt` |
| `>>` | Redirect stdout to file (append) | `echo "world" >> file.txt` |
| `<` | Take input from file | `sort < file.txt` |
| `2>` | Redirect stderr | `command 2> errors.log` |
| `&>` | Redirect both stdout and stderr | `command &> output.log` |

**Scripting Basics:**
A Bash script is a file containing shell commands. Structure:
```bash
#!/bin/bash          # Shebang — tells system which interpreter to use
# This is a comment
echo "Hello, World!" # Print output
name="John"          # Variable assignment
echo "Hi, $name"     # Variable reference
```
